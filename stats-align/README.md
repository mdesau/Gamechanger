# Stats Align Pipeline

Player statistics processing and alignment pipeline for youth baseball leagues.

## Overview

This tool manages the statistics pipeline, ensuring accurate tracking and reporting of player performance data.

## Features

- Statistics data processing
- Player performance tracking
- Data alignment and validation

## Installation

1. Open your Google Sheet
2. Go to **Extensions → Apps Script**
3. Copy the contents of `StatsAlignPipeline.gs`
4. Paste into Apps Script editor
5. Save the project
