# AutoUpdate Regs to Stats

Automated synchronization of registration data to player statistics tracking.

## Overview

This tool automatically syncs player registration information to your stats tracking system, ensuring data consistency across your league management workflow.

## Features

- Automated data synchronization
- Registration-to-stats pipeline
- Error handling and logging

## Installation

1. Open your Google Sheet
2. Go to **Extensions → Apps Script**
3. Copy the contents of `AutoUpdate Regs to Stats.gs`
4. Paste into Apps Script editor
5. Save the project
